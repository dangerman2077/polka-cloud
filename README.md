# Polka

**Облачное хранилище для студентов на собственном VPS.** Студент сохраняет файл на сетевой диск Windows и видит его в браузере. Администратор создаёт учётные записи и назначает объём каждому студенту.

[Установка](#установка) · [Windows](#подключение-в-windows) · [Администрирование](#администрирование)

| Адрес | Что доступно |
| --- | --- |
| `/` | Личные файлы и папки, загрузка, просмотр, скачивание, переименование и удаление |
| `/stats/` | Число файлов, объём, квота, распределение по расширениям во всех папках |
| `/dav` и `/dav/` | WebDAV c теми же файлами и учётными данными |
| `/admin/` | Пользователи Django, квоты в МиБ, сброс паролей, отключение доступа |

## Установка

Подготовьте Ubuntu Server с systemd и sudo, свободными TCP-портами **80 и 443** и доступом к GitHub, Docker Hub и PyPI. Установщик использует Docker Compose v2. При его отсутствии устанавливает пакеты Ubuntu `docker.io` и `docker-compose-v2`. Рекомендуемая база для новой установки — Ubuntu Server 24.04 LTS.

Направьте A-запись домена на IPv4 сервера. Если есть AAAA-запись, укажите доступный IPv6 того же VPS. Разрешите входящие 80 и 443 в межсетевом экране провайдера и на VPS. Пример домена в инструкции — `files.example.org`.

Выполните в SSH-терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/dangerman2077/polka-cloud/main/install.sh | sudo bash
```

Введите домен без протокола и пути. Установщик создаст каталог `/opt/polka-cloud`, сгенерирует ключ Django, соберёт контейнер приложения и запустит Caddy. Caddy получит публичный TLS-сертификат и будет его продлевать. Перед выводом логина и пароля установщик проверит страницу входа по HTTPS и требование авторизации на WebDAV. Для доступа через IP нужен сертификат, действительный именно для этого IP. Установка настроена для домена.

### Своя копия на GitHub

Создайте пустой **публичный** репозиторий `polka-cloud` (без README и .gitignore). Распакуйте архив и откройте Git Bash в каталоге, где находятся `manage.py`, `compose.yaml` и `install.sh`.

```bash
git init -b main
git add .
git update-index --chmod=+x install.sh
git commit -m "Initial release of Polka"
git remote add origin https://github.com/OWNER/polka-cloud.git
git push -u origin main
```

Замените `OWNER` именем аккаунта. Основная команда установки настроена на `dangerman2077/polka-cloud`. Для другого аккаунта:

```bash
curl -fsSL https://raw.githubusercontent.com/OWNER/polka-cloud/main/install.sh | sudo env POLKA_REPOSITORY=OWNER/polka-cloud bash
```

Для поля **About** подойдёт описание «Личное облако для студентов на Django с WebDAV, статистикой и квотами». Темы репозитория: `django`, `webdav`, `self-hosted`, `file-manager`, `student-project`.

## Подключение в Windows

1. Откройте **Проводник → Этот компьютер → Подключить сетевой диск**. В Windows 11 команда также доступна через меню **…**.
2. Выберите букву и введите в поле «Папка» `\\files.example.org@SSL\DavWWWRoot\dav`, заменив домен своим. В мастере добавления сетевого расположения можно указать `https://files.example.org/dav/`.
3. Выберите «Использовать другие учётные данные» и введите логин и пароль студента. Для клиента нужна служба Windows **WebClient**.
4. Создайте папку и скопируйте в неё файл. В браузере откройте «Файлы» под тем же логином. В «Статистике» появится расширение файла.

## Администрирование

Войдите в `/admin/` под выданным логином. В разделе пользователей нажмите «Добавить», введите имя, пароль и квоту. **1024 МиБ = 1 ГиБ**. Обычному студенту достаточно активной учётной записи. Персональная папка получает постоянный UUID и сохраняется при смене логина.

При уменьшении квоты существующие файлы сохраняются. WebDAV возвращает **507 Insufficient Storage**, если новая запись превышает лимит. Для временного файла при замене требуется свободное место на самом VPS. Квоты ограничивают личный объём и не резервируют место заранее. Пакетная загрузка сохраняет каждый полностью переданный файл отдельно. Статистика определяет тип по последнему расширению без учёта регистра.

Снятие флага «Активный» закрывает доступ. Удаление учётной записи сохраняет её каталог для ручного восстановления. Новый студент с тем же логином получает свой UUID.
