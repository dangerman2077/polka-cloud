# Polka · Облако для студентов

Личная папка на университетском или собственном VPS. Студент загружает курсовую через браузер и открывает её из Проводника Windows под тем же логином. Преподаватель или администратор выдаёт доступ и устанавливает индивидуальную квоту.

[Установка](#установка) · [Подключение Windows](#подключение-windows) · [Администрирование](#администрирование) · [Разработка](#разработка)

| Адрес | Возможности |
| --- | --- |
| `/` | Загрузка нескольких файлов, скачивание, папки, переименование и удаление |
| `/statistics/` | Количество файлов, объём и процент занятого места по расширениям во всех личных папках |
| `/dav` | Чтение, запись, копирование и перемещение через WebDAV |
| `/admin/` | Пользователи Django, пароли, статус доступа и квоты в МиБ |

## Установка

Подготовьте VPS с Ubuntu Server 22.04, 24.04 или 26.04 и правами sudo. Направьте A-запись домена на публичный IPv4 VPS. Если есть AAAA-запись, она должна вести на рабочий IPv6 того же сервера. Откройте входящие TCP 80 и 443 в панели провайдера. В стандартной установке 443 свободен, 80 свободен или обслуживается Nginx.

Выполните на сервере в интерактивном SSH-терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/dangerman2077/polka/main/install.sh | sudo bash
```

Введите домен, например `polka.example.org`. Установщик скачает ветку main, установит зависимости, создаст базу и службы systemd, настроит Nginx, выпустит сертификат Let's Encrypt с помощью Certbot и проверит ответы сайта и WebDAV. В конце терминал покажет логин `admin` и случайный пароль. Сохраните пароль.

Откройте `https://polka.example.org/admin/`. Для подключения используйте имя из сертификата. При обращении по IP сертификат должен отдельно включать этот IP. Автоустановка рассчитана на публичный домен.

## Подключение Windows

1. Откройте **Проводник → Этот компьютер → Подключить сетевой диск**. В Windows 11 эта команда может находиться в меню **…**.
2. Выберите свободную букву и в поле **Папка** введите `\\polka.example.org@SSL\DavWWWRoot\dav`. Подставьте свой домен. В мастере добавления сетевого расположения можно использовать адрес `https://polka.example.org/dav/`.
3. Отметьте **Использовать другие учётные данные** и введите логин и пароль пользователя Polka.
4. Скопируйте файл на диск и обновите страницу браузера. Он появится в той же папке и в статистике.

Если диск не подключается, проверьте службу **WebClient** (`Get-Service WebClient` в PowerShell), доступность сайта и доверие Windows к сертификату. Для проверки самого сервера выполните команду ниже. Curl запросит пароль, успешный ответ начинается с HTTP 207.

```powershell
curl.exe -i -u student -X PROPFIND -H "Depth: 0" https://polka.example.org/dav/
```

## Администрирование

В **Пользователи → Добавить пользователя** задайте логин и пароль. Для обычного студента достаточно активной учётной записи. Сохраните пользователя, откройте его карточку и задайте лимит в разделе квоты. Например, 5120 МиБ = 5 ГиБ. Начальный лимит — 1024 МиБ. Уменьшение квоты сохраняет существующие файлы. Снятие отметки **Активный** отключает доступ. При удалении учётной записи файлы остаются на диске под прежним числовым ID.

```bash
sudo polka status
sudo polka logs
sudo polka account password admin
sudo polka account quota student 5120
sudo certbot renew --dry-run
```

### Размещение на VPS

| Компонент | Путь или адрес |
| --- | --- |
| Код и виртуальное окружение | `/opt/polka` |
| Пользователи, пароли Django и квоты | `/var/lib/polka/db.sqlite3` |
| Файлы каждого пользователя | `/var/lib/polka/users/<ID>/` |
| Ключ Django и настройки домена | `/etc/polka.env` |
| Django и WsgiDAV за Nginx | `127.0.0.1:18081` и `127.0.0.1:18082` |

Nginx принимает HTTPS на 443. Порт 80 используется для проверки домена и перенаправления на HTTPS. Для согласованной резервной копии остановите службы `polka-web` и `polka-dav`, скопируйте весь `/var/lib/polka` и `/etc/polka.env`, затем запустите обе службы. При переносе сохраняйте права владельца. Установщик предназначен для новой установки. При сбое после создания базы сохраните данные и проверьте журналы перед повторной настройкой.

### Ограничения

Квота учитывает байты содержимого файлов. Для временных загрузок и базы на диске VPS нужен запас. Статистика считает расширения без учёта регистра, включая отдельную группу файлов без расширения. Для большой коллекции время пересчёта зависит от числа файлов. Nginx принимает тело запроса до 2 ГиБ. Клиент Windows может применять меньший лимит. DAV-блокировки действуют внутри WebDAV и сбрасываются при перезапуске процесса. Одновременное редактирование одного документа через разные клиенты может привести к замене последней сохранённой версии.

## Разработка

Linux, Python 3.10+ и виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export POLKA_DEBUG=1 POLKA_FORCE_SSL=0
mkdir -p data
python manage.py migrate
python manage.py createsuperuser
python manage.py test
python manage.py runserver
```

Локальный веб-интерфейс доступен на `http://127.0.0.1:8000/`. В боевой установке WebDAV работает отдельным WSGI-приложением. Проверки в GitHub Actions охватывают Django и WebDAV, изоляцию папок, операции с файлами, статистику и общую квоту.

### Публикация собственного форка

В корне ветки `main` должны находиться `install.sh`, `manage.py` и каталоги проекта. Чтобы установить форк, укажите его и в ссылке, и в переменной установщика:

```bash
curl -fsSL https://raw.githubusercontent.com/OWNER/polka/main/install.sh | sudo env POLKA_REPOSITORY=OWNER/polka bash
```
